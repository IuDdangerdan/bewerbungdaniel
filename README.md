# bewerbungdaniel

Persönliche Website und Portfolio von Daniel Schäfer.

## Website öffnen

Nach Aktivierung von GitHub Pages:
https://iuddangerdan.github.io/bewerbungdaniel/

In **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch**, den Branch **main** und den Ordner **/ (root)** auswählen und speichern.

## Bearbeiten

- `index.html`: Texte, Bereiche, Projektlinks
- `style.css`: Farben, Layout und responsive Darstellung
- `script.js`: Fotowechsel und Datenschutzhinweise
- `assets/`: Optimierte Fotos und Video ohne Ton

Die Seite benötigt keine Installation und keinen Build. Lokal: `python3 -m http.server 8765`, dann `http://localhost:8765` öffnen.

Die vollständigen Bewerbungsunterlagen sind bewusst nicht Teil dieses Repositorys. Foto-Metadaten wurden entfernt. Keine externen Schriften, Analysewerkzeuge oder Medien-Einbettungen.

Fotos und Video sind persönliche Medien und nicht zur freien Weiterverwendung lizenziert.
